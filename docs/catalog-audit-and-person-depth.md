## 扩展围绕人物

按当前需求，不建立独立场景空间图片库，不增加空间素材槽。背景只保留简短文字。日常衣服与随身物品是可选人物特征，不成为每次生成的必填元素。

- 固定身份：五官结构、肤色、自然不对称、年龄与体型设计目标。
- 人物图：原正脸、多视角、表情、日常成片之外，增加局部与微表情、习惯动作与仪态、妆发与日常状态，共 7 类。缺少的类别显示“待补充”。
- 生活与个性：职业与能力边界、生活节奏、习惯、喜好、局限、语言表达、仪态、日常穿着、随身特征、关系与经历。
- 本次人物状态：挑选经历和日常穿着，指定动作、情绪、妆发、人物镜头和光线，应用后进入实际生图提示词和导出任务。明确习惯动作会替换人台姿势，避免冲突。
- 切换人物时清除上一人物的状态与自动细节参考；保留用户手工添加的参考。旧版本机档案保留个人修改，并合入缺失的新字段与新出厂资产。

本轮为全部 6 位角色补充生活档案、12 套文字衣橱、19 个随身特征、6 段关系和 12 段虚构经历。图片先以 Maeve 补齐 3 张人物扩展示例：五官/手部细节、妆发状态、倾听时拢发。其他人物的 3 类扩展图仍待补充，不用模板占位。

这 3 张图片由 **Codex 内置生图**生成，原始 PNG 在 `public/ip-assets/maeve-quinn/`，实际提示词在 `data/ip-prompts/maeve-*.txt`，身份与全身体型母版的关联、文件尺寸和 SHA-256 保存在人物清单中。全库当前共 29 张项目自制人物图。

## 语言、方言与声线

语言、地区变体、口音和音色分别保存。每个角色有固定默认设定，允许另记其他语言的熟练度与切换习惯。

| 角色 | 主要语言/地区标记 | 默认地区或方言设定 |
| --- | --- | --- |
| Maeve | 英语 / en-IE | 都柏林英语，轻度 |
| Amara | 英语 / en-GB | 伦敦英语，轻度 |
| Lucía | 西班牙语 / es-MX | 墨西哥中部西语；英语可工作交流，法语为生活交流程度 |
| Inès | 法语 / fr-FR | 法国法语，轻度里昂生活背景 |
| Owen | 英语 / en-US | 美国英语，太平洋西北生活背景 |
| Théo | 法语 / fr-FR | 巴黎法语；英语带轻微法语口音 |

声音页可以编辑语言、地区标记、方言、口音及强弱、音色、音高、语速、停顿、语调、惯用表达、发音说明与固定试读文本。提供墨西哥中部、西班牙中北部、阿根廷拉普拉塔、哥伦比亚波哥大西语等可编辑起点；它们是创作方向，不是对整国口音的统一定义。

配音任务可复制或导出 JSON。它保留固定声线和角色版本，方便后续配音；本轮没有实际合成音频。用户可以上传实际生成的 WAV/MP3/M4A/OGG/WebM 样本，在角色档案试听并随 JSON 备份。图片配方只包含声音设定，避免把音频数据重复嵌入图片任务。

## 验证

`pnpm build`、`pnpm lint`、`pnpm verify:ips`。校验包括文件完整性、重复描述分组、多词搜索、人物状态、旧版数据合并、角色切换、声音导出与无效档案拒绝。浏览器另核对表单保存、刷新恢复、实际音频上传/解码、按发长榜单、JSON 往返和移动端宽度。
