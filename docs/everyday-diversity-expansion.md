# 日常人物、年龄与口音覆盖

本次通过 Codex 内置生图逐项生成并接入 **24 张人像 + 24 套穿搭**。每项都有独立原始 PNG、浏览缩略图、实际提示词、尺寸和 SHA-256。人像与服装分类索引目前各有 **40 项**，与原有素材合并浏览，不按批次设置额外入口。

## 人物与日常穿着

本批人像有 **16 位男性、8 位女性**，年龄 **23–81 岁**；其中 **18 位在 45 岁以上、10 位在 60 岁以上**。人物创作定位覆盖欧洲与北美，包含不同肤色、脸型、鼻梁、眼睑、自然不对称、稀疏发际、灰发、胡茬、小胡子、山羊胡和络腮胡。保留真实纹理与年龄感，不统一为年轻精修面孔。

新增数据提供脸型和胡须字段，结合年龄、性别形象、肤色、体型、发型与创作定位筛选。原有素材没有可靠年龄或性别标注时仍显示未标注，不根据照片猜测国籍、族裔或口音。

本批穿搭为 **12 套男款、8 套女款、4 套中性款**，覆盖外出采买、邻里散步、日常社交、工作、园艺、居家、运动、雨季与冬日出行。包含短裤、背带工作裤、前开襟针织、背心裙、日常长裙、工作套装、牛仔、亚麻与保暖层次，鞋类包含平底鞋、便穿鞋、支撑步行鞋、凉鞋和工作靴。不同用途和松量有独立分类。

搭配年龄方向表示设计重点，可跨龄使用；服装不限定人物的真实年龄、性别或身体比例。指定选材始终自由。随机穿搭会优先匹配已知人物的性别形象与年龄方向，缺少匹配分类时保留原有素材池作为回退。

## 浏览与随机

索引按年龄与性别形象、版型与生活风格轮流取材，完整保留所有条目，不再依赖固定的 16 个数组位置。首页能够同时看到男性、熟龄女性、老年人与不同身体设计。

随机取样先选分类，再选分类内的图片。大量缺少人物标注的发型图作为一个分类参与抽取，避免其数量优势淹没其他人物。当前已经选定的人像继续保留，随机只替换可变的穿搭、姿势和未锁定设定。

## 语言与地区口音

语言与声音库有 **99 条记录**，其中 **40 条语言地区口音方向**：英语 13、西班牙语 12、法语 4、德语 3、葡萄牙语 2、意大利语 1、荷兰语 1、中文普通话方向 3、粤语 1。另有 59 条多语切换、音色、音高、语速、语调、惯用表达、发音与声音一致性记录。

语言、地区范围和国家语言标记可以组合筛选。同一标记可以对应多个地区方向，例如 en-US 的美式日常、美国南部、新英格兰与纽约都会区；es-MX 的墨西哥中部与北部独立保存。每条方向包含口音强度、个人发音要求和试读文本；音色与节奏另选，随机搭配尊重语言适配条件，不根据外观推定口音。

语言地区标记参考 [Unicode CLDR](https://www.unicode.org/cldr/charts/49/summary/en.html)；西语名称参考 [RAE / ASALE](https://www.rae.es/dpd/espa%C3%B1ol)。城市口音属于人物创作方向，国家语言标记本身不能完整描述具体个人口音。实际音频需由支持对应方向的声音模型或固定个人样本实现，本批没有生成音频或模仿具名真人。
