# 七类人物素材库

本批补入 **44 张实际原创图片**，均通过 Codex 内置生图生成并保留 PNG 原图：16 张人像、16 套服装、12 组状态与细节参考。它们可以直接从图库加入配方，不要求先创建角色档案。

## 实际素材与分类

| 图库 | 本批新增 | 默认展示与分类 |
| --- | ---: | --- |
| `/portraits` 人像 | 16 | 新增 16 张 + 自有角色母版 6 张；年龄、性别形象、肤色、体型、创作定位及发型 |
| `/costumes` 穿搭 | 16 | 男款 6、女款 6、中性 4；版型、用途、松量、生活风格、季节、搭配结构 |
| `/poses` 姿势 | 0 | 保留原有 1,439 张与白模 / 深度视图 |
| `/expressions` 表情 | 4 | 加上已有角色表情板 6 组，共 10 组；情绪、口形与眼神 |
| `/grooming` 妆发 | 2 | 加上已有角色妆发 1 组，共 3 组；梳理、淡妆、胡须状态 |
| `/body-details` 体型细节 | 4 | 加上已有体型母版 6 组、人物细节 1 组，共 11 组；体型、手部、侧脸和皮肤细节 |
| `/mannerisms` 习惯仪态 | 2 | 加上已有仪态 1 组，共 3 组；倾听、开放手势与自然站姿 |

新增人像年龄 **24–75 岁**，包含男性 8、女性 7、中性形象 1，覆盖四个成年年龄段和不同肤色、体型。欧洲 / 北美是虚构人物的创作定位，不是根据照片识别的国籍或族裔。人像正脸采用统一简洁拍摄条件便于比较五官；穿搭、表情、身体与仪态由各自的图库控制。

新增服装包含成熟通勤、工作服、运动、居家、户外、经典正装、旅行、银龄舒适、大码和娇小成年版型，采用无脸人台展示，合成时按当前人物身材适配。

## 原库整理

原人像 1,499 张、服装 1,407 套均保留，分别可切换到“原库”或“全部”。人像原库按正脸 / 氛围、发长、发型家族、刘海、原榜单和精选分类；服装原库按季节、主题、搭配结构及原始单品颜色标签分类。重复服装描述可以分组及展开查看同描述变体，图片并未仅因文字相同而删除。

原库元数据没有年龄、性别、肤色或地域字段，不把猜测当成标注。新增标签来源为 `design_spec`，原有标签来源为 `source_metadata`。原库检查保存在 `data/catalog-audit.json`，其统计仅描述原库，见 `/library-quality`。

## 合成链路

侧栏、总览、底部配方栏和创作台都连接七类图片。表情、妆发、身体参考、仪态都有图片和可编辑的“本次参考目标”，选择后进入同一有序参考清单与提示词，并保存在浏览器中。同类状态可替换；全身姿势和习惯手势同时保留，冲突时以整体姿势及人体合理性为准。随机搭配保留已选人像。

参考职责分别限定：人像控制五官、年龄和肤色；服装只控制单品；姿势只控制动作；表情与妆发调整状态；身体参考在已有角色母版下尊重固定体型；仪态补足细微手势。其他参考演员不能替换当前人物身份。

创作台支持复制 Codex 生图任务、导出 JSON、下载带编号的参考拼图。内置生图最多接收 5 个图像附件，超过时导出任务带有 `inputPlan`：**身份原图单独输入 + 其余参考的拼图**，仍按逻辑编号“图 N”对应清单。只需两个附件即可使用七类参考。原 API 与 ComfyUI 接口继续保留。

语言、方言、口音和声音样本仍在自有 IP 的声音档案中管理，包含西班牙语地区预设；这批只生成图片，不把声音设定冒充可播放语音。

## 文件与复核

- `public/library-assets/`：44 张 PNG 原图，另有浏览用 WebP 缩略图。
- `data/catalog-generation-specs.json`：每张图片的实际生成提示词与创作设定。
- `data/catalog-assets.json`：尺寸、字节数、SHA-256、缩略图路径与人工视觉检查状态。
- `data/catalog-expansion.json`：前端分类索引，包含既有角色参考板的缩略图映射。
- `public/library-examples/` 与 `data/library-demo-task.json`：实际七库合成的 Nadia 示例，保存成片 PNG、参考拼图、完整提示词、有序参考与两个附件的输入计划。示例成片单独计数，不算入 44 张库内素材。
- `scripts/build-catalog-index.mjs`：从已保存素材记录重建分类索引。
- `pnpm verify:catalog`：验证图片与哈希、分类覆盖、七类参考顺序、使用目标与持久化。
- `pnpm verify:ips`：验证既有角色资产和档案。

这是一批可以使用和继续扩充的素材，原库尚未完成逐张人口属性标注。后续补图沿用上述设定、原图、生成记录和视觉检查流程。不建立场景空间图资产库。
