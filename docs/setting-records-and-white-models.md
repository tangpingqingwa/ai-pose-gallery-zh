# 图像素材与人物设定记录

选材界面统一按素材特征分类，不用“新增 / 原库”组织浏览。来源和生成记录仍保存在数据文件中，用于维护和复核。

## 可复用的白模参考

四个状态图库现使用 **23 张 Codex 内置生图生成的素体白模 PNG**：

| 图库 | 数量 | 控制目标 |
| --- | ---: | --- |
| 表情神态 | 6 | 微笑、大笑、解释口形、思考、惊讶、疲惫 |
| 妆发状态 | 5 | 短发、低发髻、自然卷、短胡须、素净面部状态 |
| 体型细节 | 7 | 修长、常规、结实、丰盈、娇小成年比例、圆肩体态、手部细节 |
| 习惯仪态 | 5 | 倾听、开放手势、扶下颌、放松重心、拢发 |

白模只控制对应结构和状态，不复制其五官比例、白色材质或多视图布局。人像母版确定身份与肤色；已有 IP 的固定身体母版与身材设定继续约束体型。通用图库不再重复收录具体角色的真人状态板，旧配方中的通用状态参考自动迁移到相应白模，手动上传与人物身份母版保留。历史生成文件不被删除。

## 两类设定记录库

`/traits` **个性与生活库**有 64 条起始记录，分为性格、职业与能力、成长经历、日常节奏、习惯、喜好、局限、说话方式、表情肢体习惯、人物一致性 10 类。

`/voices` **语言与声音库**有 52 条起始记录，分为语言与地区口音、其他语言与切换、音色、音高、语速、语调、惯用表达、发音与姓名读法、声音一致性 9 类。语言记录包括四种西班牙语地区方向、英语、法语、葡语、德语、普通话与粤语等。地区语言、口音和试读文本作为一组，个人声线与节奏另选，避免随机把不相容的语言字段拼在一起。

每条记录可创建、编辑、删除、搜索、按类型筛选、JSON 导入和导出。个人修改保存在当前浏览器 IndexedDB 中，不会自动同步到其他设备；导出文件可用于备份和迁移。

## 指定、随机与固定到 IP

1. 从图库选择人像、穿搭、姿势及需要的白模。
2. 从记录库指定职业、语言等重要项，或在创作台逐项选择。指定选择默认锁定。
3. 点击“随机关联设定”，仅替换未锁定项；也可以只随机生活设定或声音设定。
4. 关联既有自有角色后，可点击“固定到当前 IP”。关联记录的完整内容与编号写入角色，所有固定项锁定，后续载入沿用。

记录库中的编辑不会悄悄改变已关联的人物：配方与角色保存所选内容，显式重新关联后才更新。手工编辑人物生活或声音字段时，仅解除内容已经改变的对应关联，避免旧记录再次覆盖手工修改。固定新设定不会删除已有音频样本。

生活与个性进入图像创作提示词；语言、口音、声线和试读文本进入配音任务。静态图片不渲染对白，也不把音频指令当作视觉元素。任务导出、生成历史和收录成片保留关联记录，便于后续延续同一人物。

## 文件

- `public/white-models/`：23 张白模 PNG 与浏览 WebP，约 33.5 MiB 原图。
- `data/white-model-generation-specs.json`：实际使用的完整生成提示词与参考职责。
- `data/white-model-assets.json`：尺寸、SHA-256 与视觉检查状态。
- `data/white-model-references.json`：四个通用图库的索引。
- `data/setting-records.json`：116 条、19 类起始人物设定记录。
- `scripts/verify-setting-library.mjs`：验证随机锁定、关联内容稳定、语言字段优先级、IP 固定、音频保留、旧参考迁移及白模哈希。

运行 `pnpm verify:settings`、`pnpm verify:catalog`、`pnpm verify:ips`、`pnpm build` 与 `pnpm lint` 检查。
