# 人像、穿搭与语言声音扩充

本轮逐张生成并收录 **24 张人像 + 24 套日常穿搭**，并补充 **48 条语言与声音设定**。带分类的人像累计 **104 项**、穿搭 **64 项**，语言与声音库 **147 条**；个性与生活库继续保留 64 条，总设定记录 **211 条**。

## 人物与穿搭

本轮人物男女各 12 位，18–29、30–44、45–59、60+ 各 6 位，涵盖亚洲、欧洲、北美、拉美与非洲的虚构人物设计。发型增加男性中长发、长脏辫、女性寸头与短卷发，保留不同鼻型、眼睑、脸型、灰发、发际线、胡须与体型，避免统一精修脸。

24 套穿搭分为男款 10、女款 10、中性 4，重点增加连体工装、针织长连衣裙、衬衫裙、披风、马甲、半裙、裙裤、围裙、连体阔腿裤、长衬衣及完整家居套装。年龄方向、版型、松量、季节和用途可以分别筛选。常用选项直接显示，详细分类按需展开。

首页与随机选材纳入服装结构分类，避免只轮换相似的外套与长裤组合。人像继续按设计地区、年龄与性别形象交错排列，随机人物保留地区分组逻辑。已固定人像时，随机穿搭仍优先匹配其形象与年龄方向。

## 语言与个人声音

语言地区方向从 40 扩至 **64 条**，补充日语标准与关西方向、韩语首尔与釜山方向、台湾普通话、新加坡华语、东北韵律、广州粤语，以及印地语、泰米尔语、孟加拉语、乌尔都语、印尼语、马来语、泰语、两种越南语地区方向、土耳其语、两种阿拉伯语地区方向、波兰语、瑞典语、多米尼加西语和肯尼亚斯瓦希里语。

另补充 24 条多语切换、音色、音高、语速、语调、惯用表达、个人发音及声音一致性记录。每条语言方向有独立的强度、发音说明和生活试读脚本；文字覆盖购物、衣物、修补、做饭、天气、地址和回忆。日语、韩语、中文和阿拉伯语具有相应的多语切换选项。

语言记录按主要语言、地区分组、国家语言标记检索，同一国家标记下的城市方向独立保存。声音页交错展示不同语言，音色与节奏各自选择。阿拉伯语和乌尔都语试读区域自动使用合适的文字方向。

切换主要语言时，清理不适配的未锁定语言专属记录，保留独立音色与节奏；如果不适配记录已锁定，则提示先解锁并保留当前选择。指定惯用表达时也会检查当前主要语言或角色基础语言。被拒绝的关联不会触发 React 错误，也不会显示保存并关联成功。

语言地区标记参考 [Unicode CLDR 标识符规范](https://www.unicode.org/reports/tr35/#Unicode_Language_and_Locale_Identifiers)，地区范围为选材分组。城市口音的实际表现仍由支持对应方向的声音模型或自有固定样本校准。本轮声音交付为设定记录及试读脚本，未生成试听音频。

全部图像使用 **Codex 内置生图与内置图像编辑**。每个最终条目有独立 PNG 原图、WebP 浏览预览、实际提示词、尺寸和 SHA-256。

- 穿搭：C-NEW-041 至 C-NEW-064，位于 `public/library-assets/costumes/`；C-NEW-053 与 C-NEW-059 使用独立的 `-v2.png` 最终文件。

- P-NEW-086、P-NEW-089 的胡须按实际成图校正标注，生成提示词保留原文。
- `data/catalog-generation-specs.json` 保存生成及编辑提示词、初稿哈希、修订原因与分类；`data/catalog-assets.json` 保存最终文件哈希和尺寸。

既有自有 IP 档案、人物资产和原始参考素材继续保留。图像与声音分别进入对应创作任务，外观设计不自动决定语言、声线或性格。
