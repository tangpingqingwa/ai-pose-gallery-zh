# 自有写实 IP 角色库

在原有姿势、服装、人像与合成台之上增加 `/characters`。首批 6 位原创虚构成年角色，各自关联五官、皮肤与头发、体型设计、人设、穿搭、声音描述及生成资产。

本轮所有新增图片均使用 **Codex 内置生图** 制作，没有使用自定义中转服务。

## 使用链路

1. 从“自有 IP 角色库”打开角色，查看固定外貌、身材目标及人设。
2. 在“关联资产”或“继续创作”选择一套造型。“载入这套造型”会同时关联角色母版、全身体型参考、服装、姿势与场景。
3. 在合成台自由更换服装和姿势，调整场景，复制或导出 **Codex 生图任务**。
4. 在 Codex 聊天中按任务清单附上图片，使用内置生图执行；生成结果上传回所属角色，视觉核验后标记验收。
5. 通过原有 API 生成的图片也可从历史记录收录到所属角色，保存角色版本、来源参考与配方。

浏览器页面不能直接调用 Codex 聊天的内置工具，所以本版本采用“任务 + 有序参考图”衔接，按钮不会伪装成内置 API。原有云端与 ComfyUI 方式继续可用。

原人像库新增“自有角色”筛选，新增人像选择时会同时带入完整角色设定；改选普通参考人像时解除旧角色与旧体型参考，避免不同人物的设定混用。

## 资产与数据

- `data/ip-characters.json`：角色档案和资产溯源。
- `data/ip-looks.json`：造型配方，使用已有图库的实际 ID。
- `data/ip-prompts/`：本轮内置生图的提示词集。
- `public/ip-assets/<slug>/`：原始生成 PNG，基础参考与造型成片分别命名。
- `src/lib/characters.ts`：身份快照、角色与配方关联、导出及导入校验。

页面中的新建、编辑和收录记录保存在当前浏览器本机，支持导出/导入 JSON 备份。浏览器中的修改不会自动写回 GitHub。随项目提交的初始档案和图片可通过版本库持续维护。

身高、体重、围度、肩宽与腿长都是 **设计目标**，不是从照片实测的三维数据。图像验收关注身份、年龄、体型轮廓、肩腰臀比例、服装和动作的一致性，不宣称厘米级准确。

库内服装和姿势仍按原作者条款作为创作参考；本轮未把下载的参考原图复制进新增公开素材包。Lucía 的红色针织造型增加白色高领内搭，作为明确的搭配调整记录。两套男装是自定义文字设定，不冒充来自原服装库。

## 本地运行与验证

```sh
pnpm install --frozen-lockfile
pnpm dev --host 127.0.0.1
pnpm verify:ips
pnpm build
pnpm lint
```

建议使用 Node.js 24 或更新版本运行 `verify:ips`（使用原生 TypeScript 类型擦除）。

Vite 在本地缺少旧图库图片时按需跳转到当前 fork 的图片地址，不做预先批量下载；可用 `GALLERY_ASSETS_ORIGIN` 更换素材地址。新生成的图片完整位于 `public/ip-assets/`，由 Vite 自动打入构建产物。完整发布原有图库仍沿用 `scripts/build.sh` 复制数据与旧素材。

验证包括角色/资产唯一性、文件哈希与尺寸、服装与姿势编号、母版关联、身份快照、切换角色时清理旧体型、任务导出和无效导入；浏览器另查造型载入、复制任务、刷新保留、档案编辑、JSON 导入导出和移动布局。
